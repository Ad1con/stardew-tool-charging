[size=4][b]Tool Charging[/b][/size]

Increase the charge speed of upgraded tools. When charging up an upgraded hoe or watering can, the transition from one tile to multiple tiles happens quicker.

Upgraded tools hit more tiles the longer you hold the button; this mod shortens that amount of time.

This is [url=https://github.com/mralbobo/stardew-tool-charging]mralbobo's Tool Charging[/url], updated for Stardew Valley 1.6. The idea and the original implementation are theirs; the original was last updated in 2018 and no longer loads. This version ports it to SMAPI 4, changes the setting to a speed multiplier, and adds Generic Mod Config Menu support. Same GPL-3 license.

[size=3][b]Install[/b][/size]
1. Install [url=https://smapi.io/]SMAPI[/url].
2. Unzip the mod into Stardew Valley/Mods.
3. Run the game through SMAPI.

[size=3][b]Config[/b][/size]
One setting, editable in-game with [url=https://www.nexusmods.com/stardewvalley/mods/5098]Generic Mod Config Menu[/url] or in config.json:

ChargeSpeedMultiplier (default 2.0) — how much faster than normal a tool charges. 1.0 is the game's normal speed, 2.0 is twice as fast, 10.0 is ten times. Clamped to 1–50.

[size=3][b]Compatibility[/b][/size]
• Stardew Valley 1.6+ and SMAPI 4.0+. Tested on Stardew Valley 1.6.15 with SMAPI 4.5.2.
• Works in multiplayer and split-screen.
• No Harmony patches, no asset changes. The only thing this mod writes to is the game's own charge timer (Farmer.toolHold) on your own player, so it shouldn't conflict with anything unless another mod also changes tool charge speed.
